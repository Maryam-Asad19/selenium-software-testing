# Softwaretest-Projekt mit Selenium

Dieses Repository enthält ein Softwaretest-Projekt, das mit Selenium umgesetzt wurde.
Das Projekt liegt in Form eines Jupyter Notebooks vor und dient zum Üben von automatisierten Tests.

## Verwendete Technologien

- Python
- Selenium
- Jupyter Notebook

## Projekttyp

Studienprojekt / Universitätsaufgabe

## Projektbeschreibung

Ziel dieses Projekts ist es, grundlegende Konzepte des automatisierten Softwaretestens
mit Selenium zu erlernen, einschließlich Browser-Automatisierung und einfacher Testszenarien.

## Ausführung

1. Python installieren
2. Selenium installieren
3. Das Notebook `PL32_Selenium_L.ipynb` öffnen
4. Die Zellen Schritt für Schritt ausführen
